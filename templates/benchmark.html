측정 차이에는 안티앨리어싱, 선 두께, 좌표 필터, 축소 방식이 함께 반영됩니다. 학습 그림과 평가 표본이 겹치는지는 확인되지 않았습니다.

실패 및 누락 상세

    모델 입력 비교

    완성 그림의 64×64 입력 픽셀과 상위 5개 예측입니다.

    클래스별 결과

    측정 방법
    평가 데이터
    공개 Quick, Draw! 원본 데이터에서 32개 클래스, 클래스당 20장을 추출합니다. 정답은 참가자가 받은 제시 단어입니다. Quick, Draw! 데이터 문서
    Canvas PNG
    획 종료 시 512×512 캔버스를 PNG로 전송합니다. 서버에서 회색조로 변환하고 BOX 방식으로 64×64로 축소합니다. 흰색은 0, 검은색은 1이며 중간 회색을 유지합니다.
    현재 벡터
    같은 그림의 누적 좌표를 전송합니다. 기존 좌표 필터와 축소 규칙을 적용하고 Bresenham 방식으로 64×64 이진 입력을 만듭니다.
    정확도
    완성 그림에서 정답이 1위 또는 상위 5개에 포함된 비율입니다. 하나의 가중치로 345개 출력을 평가하며 이름표가 없는 17개는 인덱스로 표시합니다. 정확도 차이는 벡터에서 PNG를 뺀 값입니다.
    속도와 전송량
    워밍업 10쌍 이후 획마다 두 요청의 순서를 번갈아 바꿉니다. 응답 시간은 브라우저에서 요청 인코딩을 시작한 시점부터 응답을 읽기까지이며, 전송량은 요청 본문 크기입니다.
